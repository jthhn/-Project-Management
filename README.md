# Mini Project Management API

A simple RESTful API for managing Projects and Tasks with role-based access control, built with Django REST Framework.  
Dockerized and ready for production!

---

## 🚀 Tech Stack

- Python 3.11
- Django 4.x
- Django REST Framework (DRF)
- PostgreSQL 14
- Simple JWT Authentication
- Docker & Docker Composemanagement-
- Swagger / OpenAPI Documentation
- Django Filter (for task filtering)

---

## 📦 Features

- JWT authentication (Login / Register)
- User roles: Admin, Project Manager, Developer
- CRUD operations for Projects and Tasks
- Task assignment to Projects and Users
- Task priority, status, due dates
- Filtering, searching, and pagination for Tasks
- Role-based access control
- Swagger Documentation (`/swagger/`)
- Fully Dockerized for easy deployment
